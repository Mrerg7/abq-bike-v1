# ABQ.Bike

Informational static site for an Albuquerque bike brand concept.

**Domain available for acquisition** → [sales@desertrich.com](mailto:sales@desertrich.com) · $100,000 · Serious inquiries only

## Local development

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 43123
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Deploy

- **Build command:** `npm run build`
- **Deploy command:** `npx wrangler deploy`
